# canvas: ../kitchen-sink.canvas
# Comments on the kitchen sink: a point, a sticky, a page element, two
# regions, a draft left empty, a draft with two lines, focusing a pill,
# delete and undo, annotating a selection, resolving, and an undo of all of
# it. The camera has the page `page-desktop` at screen (250, 50) and the
# empty canvas left of and below it.
camera -2150,-1650,1
expect saved same-as ../kitchen-sink.canvas
expect count comments 12

# a sticky to comment on, made with the sticky tool
tool sticky
click 700 760
type plan
key escape
key escape

# a point on empty canvas
tool comment
click 120 480
type Spacing feels off here
key enter
expect count comments 13

# a comment on the sticky is a canvas point: a sticky is not a page
click 740 800
type Make this one bigger
key enter

# a click on a page asks it for the element. The synthetic page answers
# with a cell of its grid, outlined while the draft is open.
click 900 480
wait 100
type This cell needs a heading
key enter
expect count comments 15

# a region dragged on empty canvas
press 60 600
drag-to 140 640
drag-to 220 700
release
type Move this block up
key enter
expect count comments 16

# a region dragged over a page grabs the cells under it, so it is a region
# of the page's document.
press 560 200
drag-to 700 260
drag-to 820 330
release
wait 100
type Over a page
key enter

# a draft left empty is dropped with Escape and leaves nothing
click 400 760
key escape
expect count comments 17

# Shift+Enter breaks the line, and Enter commits
click 400 760
type first line
key shift+enter
type second line
key enter
# six comments in Electron's shape: three points, one on a page's element,
# a region on the canvas and a region of the page's document
expect count comments 18

# a click on a pill focuses its comment, Escape lets go of it
key escape
click 120 480
key escape

# Delete removes the focused comment, undo brings it back
click 120 480
key delete
expect count comments 17
key cmd+z
expect count comments 18

# annotate a selection of two items
tool select
select page-shape page-drawing
act annotate-selection
type Both of these
key enter
expect count comments 19

# resolve the focused comment, which is the one just made
act resolve-comment
expect saved /annotations/-1/status = resolved

# undo all of it. The click on empty canvas takes the keys back from the
# right panel's field, where a window with one leaves them after a comment
# is sent.
click 40 950
undo-to-start
