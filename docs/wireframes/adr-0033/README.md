# ADR 0033 wireframes

Pre-implementation wireframes for [ADR 0033](../../adr/0033-user-chosen-space-folder.md)
(user-chosen space folder): the onboarding space step, the Settings General
pane, and the space-missing-at-boot prompt. Kept as static HTML/CSS references
for the flows they sketch.

The shipped code is authoritative — these predate implementation and may have
drifted from the final UI.
