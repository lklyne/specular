Road 3 of 6 · asymmetric

Publish & comment

Editing stays local and solo. "Share" publishes a snapshot to a URL. Others open it in a browser, pan around, and leave comments that flow back to you. Nobody else ever edits your canvas.

What you get

  • The share link people actually want. Most "can you share this" requests are a review, not a co-editing session.
  • Un-share genuinely works. The published copy is a separate artifact — delete it and it's gone. In live multiplayer, every guest holds a full replica you can never take back.
  • A real consent moment. You publish a version, deliberately, rather than opening a live window onto your working file.
  • No hard problems. No live sync server, no presence, no multiplayer undo, no merge semantics, no per-canvas document splitting.
  • Live pages become tractable. A snapshot has pixels; there's no confusion about whose localhost a shared page points at.

What you give up

  • Co-editing and presence. Two people cannot be in the same canvas.
  • Freshness. Republishing is a manual act — or automatic, at which point you've quietly rebuilt a live feed with none of the safeguards.
  • Remote agents editing. An agent can read a published canvas but has nowhere to write.
  • The privacy absolute. The server reads what you publish, because it has to render it.
Underrated property: this is the only road where "what changed since you last looked" is trivial, because versions are discrete. In a live CRDT there is no version — just a continuously moving present, and every review workflow has to invent one.

Support burden

A snapshot upload, a static viewer, and a comment write-back. No Durable Objects, no CRDT server, no auth beyond an unguessable URL.

Who does this

Figma's prototype links before multiplayer. Loom. Whimsical share links. Google Docs "published to the web." Almost every design tool shipped this before it shipped co-editing, because it's where the value density is.

The strategic read: the cheapest road that produces a link, and the one most likely to reveal whether anyone actually wants co-editing. If reviewers only ever comment, Road 4 was never necessary.
