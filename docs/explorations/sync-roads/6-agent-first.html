Agent-first

Humans mostly work alone. The multiplayer that matters is you and the agents you delegate to. The canvas is a shared workspace between a person and a set of processes — and a local agent needs no server at all.

Shape

Click a box.
The observation this road is built on: agents already drive the canvas today, through a local CLI, with no cloud involved. Everything valuable about "multiplayer" — something else changing your canvas while you watch — already works. What's missing isn't sync. It's knowing what happened.

What's actually missing

  • Attribution. Entities have no author field. Comments know user vs agent but not which one. After an hour of agent work, the canvas can't tell you who made what.
  • Change review. There's no "here's what the agent did while you were away — keep this, drop that." Undo is a linear stack, not a diff you can accept in pieces.
  • An activity timeline. Spatial tools lose history; a canvas that several actors touch needs a readable record of the touching.
  • Batch revert. The unit an agent works in is a task, not a keystroke. Undo should have a granularity that matches.

Presence is the exception — live agent cursors already exist and already work.

What you get

  • The differentiated workflow, not a smaller Figma. Design tools with human multiplayer are a crowded field; design tools built around delegating to agents are not.
  • Privacy for free. Local agents mean no server, no custody, no consent surface — Road 1's posture with none of its limitations.
  • Cheap. Attribution and review are product work, not distributed-systems work.
  • It composes with every other road and forecloses none of them.

What you give up

  • Human collaboration is deferred, possibly indefinitely.
  • No share link unless you also take Road 3 or 5.
  • A bet on a premise: that the audience is one designer with agents, not a team.

Who does this

Claude Code and Cursor — enormously valuable, effectively single-player, with the collaboration being human↔machine. Neither has multiplayer and neither is hurt by that.

The strategic read: this road argues the whole sync question is downstream of a product question nobody's answered — whether the second actor in a canvas is a colleague or a process. If it's a process, most of the cloud architecture is solving for a user who isn't there.
